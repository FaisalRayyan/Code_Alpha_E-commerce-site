# ShopSphere — Premium Joggers E-commerce Store

ShopSphere is a premium full-stack e-commerce application
being developed as part of my CodeAlpha Full Stack
Development internship.

The project will combine a highly animated and responsive
frontend with a Django backend, database-driven products,
shopping cart, authentication, checkout, and order processing.

## Current Progress

Day 1 project foundation completed.

## Technology Stack

### Frontend

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- GSAP
- Swiper.js
- AOS

### Backend

- Python
- Django
- Django ORM

### Database

- SQLite for development
- PostgreSQL planned for deployment if required

## Planned Features

- Premium animated homepage
- Product listings
- Product details
- Categories
- Search and filters
- Shopping cart
- Wishlist
- User authentication
- Checkout
- Order processing
- Customer order history
- Admin product management
- Admin order management
- Responsive design
